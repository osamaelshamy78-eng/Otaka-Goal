# Otaka Goal

مركز مباريات بالعربي والإنجليزي: نتائج مباشرة، ومواعيد بالتقويم، وصفحة لكل مباراة، وترتيب وهدافين لسبع بطولات:
دوري أبطال أوروبا، الإنجليزي، الإسباني، الإيطالي، المصري، السعودي، الإماراتي.

A bilingual (Arabic/English) football match center: live scores, a fixtures calendar, match pages, standings and top scorers.

## التشغيل محلياً

```bash
npm install
npm run dev        # http://localhost:3000 → /ar
```

- `/ar` العربي (من اليمين للشمال)، و`/en` الإنجليزي.
- `/ar?date=2026-10-10&league=epl` مباريات يوم معيّن وبطولة معيّنة.
- `/ar/match/<id>` صفحة المباراة، `/ar/standings?league=egy` الترتيب، `/ar/scorers?league=spl` الهدافين.

## مصدر البيانات

| المتغير | المصدر | البطولات |
|---|---|---|
| `FOOTBALL_DATA_KEY` | [football-data.org](https://www.football-data.org/client/register) (مجاني) | أبطال أوروبا، الإنجليزي، الإسباني، الإيطالي |
| `API_FOOTBALL_KEY` | [API-Football](https://dashboard.api-football.com) | المصري، السعودي، الإماراتي |

- لو المفتاحين موجودين، كل مصدر بيجيب بطولاته.
- لو مفيش ولا مفتاح، الموقع بيشتغل **ببيانات تجريبية** لموسم 2026/2027.
- الخطة المجانية من API-Football بتغطي أمس والنهارده وبكرة بس، ومن غير ترتيب وهدافين الموسم الحالي، و10 طلبات في الدقيقة.
- football-data.org المجاني: 10 طلبات في الدقيقة، والنتايج المباشرة ممكن تتأخر، وتفاصيل الأهداف والكروت مش دايماً متاحة.

محلياً: `cp .env.example .env.local` وحط المفاتيح. وعلى Vercel: Project → Settings → Environment Variables.

الطلبات الناجحة بس هي اللي بتتحفظ مؤقتاً (مباريات النهارده دقيقة، الأيام الجاية ربع ساعة، اللي فاتت والترتيب ساعة)، علشان رفض بسبب الحد ما يفضلش ظاهر.

## الهيكل

| المسار | الوظيفة |
|---|---|
| `src/app/[lang]/` | الصفحات (المباريات، المباراة، الترتيب، الهدافين) |
| `src/components/` | اللوجو، الهيدر، شريط الأيام والتقويم، صف المباراة، التنبيه |
| `src/lib/data/` | مصادر البيانات: `sample.ts` التجريبي، `football-data.ts`، `api-football.ts`، و`index.ts` بيختار بينهم |
| `src/lib/i18n.ts` | نصوص الواجهة باللغتين |
| `src/lib/leagues.ts` | البطولات والقنوات الناقلة |
