# Otaka Goal

مركز مباريات بالعربي والإنجليزي: نتائج مباشرة، ومواعيد بالتقويم، وصفحة لكل مباراة، وترتيب وهدافين لسبع بطولات:
دوري أبطال أوروبا، الإنجليزي، الإسباني، الإيطالي، المصري، السعودي، الإماراتي.

A bilingual (Arabic/English) football match center: live scores, a fixtures calendar, match pages, standings and top scorers.

## التشغيل محلياً

```bash
npm install
npm run dev        # http://localhost:3000 → /ar
```

- `/ar` العربي (من اليمين للشمال)، و`/en` الإنجليزي.
- `/ar?date=2026-10-10&league=epl` مباريات يوم معيّن وبطولة معيّنة.
- `/ar/match/<id>` صفحة المباراة، `/ar/standings?league=egy` الترتيب، `/ar/scorers?league=spl` الهدافين.

## مصدر البيانات

من غير مفتاح، الموقع بيشتغل **ببيانات تجريبية** متولّدة لموسم 2026/2027، وحالة الماتشات بتمشي مع الساعة الحقيقية.

علشان البيانات الحقيقية، حط مفتاح [API-Football](https://dashboard.api-football.com) في متغير البيئة `API_FOOTBALL_KEY`:

```bash
cp .env.example .env.local   # وحط المفتاح جوه
```

وعلى Vercel: Project → Settings → Environment Variables → `API_FOOTBALL_KEY`.

- الطلبات بتتحفظ مؤقتاً: النهارده كل 30 ثانية، الأيام الجاية كل 15 دقيقة، والأيام اللي فاتت كل ساعة.
- الخطة المجانية فيها 100 طلب في اليوم وممكن ما تشملش الموسم الحالي؛ راجع خطتك.
- أرقام البطولات في `src/lib/leagues.ts`، والترجمة العربية لأسماء الفرق في `src/lib/teams.ts`.

## الهيكل

| المسار | الوظيفة |
|---|---|
| `src/app/[lang]/` | الصفحات (المباريات، المباراة، الترتيب، الهدافين) |
| `src/components/` | اللوجو، الهيدر، شريط الأيام والتقويم، صف المباراة، التنبيه |
| `src/lib/data/` | مصدر البيانات: `sample.ts` التجريبي و`api-football.ts` الحقيقي |
| `src/lib/i18n.ts` | نصوص الواجهة باللغتين |
| `src/lib/leagues.ts` | البطولات والقنوات الناقلة |
